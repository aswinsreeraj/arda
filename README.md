# ARDA

ARDA (Auditable, Reliable, Durable Agents) is a multi-tenant platform for governed AI agent execution.

## Architecture

- `arda`: Go backend services and shared infrastructure contracts.
- `arda-reliability`: Python-based reliability scoring and retrieval service.
- `arda-frontend`: React and TypeScript frontend.

## Development

The project is under active development. Setup instructions will be added as the development environment is established.
